# 恢复与卸载

操作前先从托盘完全退出 Claude。不要删除 `%LOCALAPPDATA%\Claude-3p` 或 `%LOCALAPPDATA%\ClaudeZhPatch`，其中含现有配置与备份。

## 安装中断

查看 `%LOCALAPPDATA%\ClaudeZhPatch\backups` 下最新目录中的 `migration.json`。它记录每个阶段、数据来源路径、备份文件的 SHA256 和目标安装目录。

| 阶段 | 含义 | 建议 |
| --- | --- | --- |
| `backing-up` | 备份未全部完成 | 原商店包未卸载，排除文件占用或磁盘空间问题后重新安装 |
| `prepared` | 数据备份和程序均已就绪 | 若商店版仍在，重新运行安装；若已被卸载，运行 `setup.cmd resume` |
| `store-removed` | 商店版已移除，后续设置未完成 | 运行 `setup.cmd resume` |
| `complete` | 安装完成 | 直接从开始菜单打开 Claude |

`resume` 只在商店版已不在时继续，不执行卸载。它先验证备份和中文程序，再补回缺失的非商店数据文件、保存中文配置并修复快捷方式；不会用旧备份覆盖已有的新设置。商店包私有目录完整保留在备份中，不会自动重建整个 Packages 目录。

若 `setup.cmd resume` 报错，请停止操作并保留备份。不要为了继续而改写 `migration.json`，也不要把完整备份公开上传。

## 恢复原语言

在补丁目录打开 PowerShell：

```powershell
.\setup.cmd restore-language
```

这只恢复最近一次成功安装前的 `locale` 字段；若此前没有该字段就移除它，保留现有网关、密钥等其他设置。它不会恢复商店注册或 Cowork 服务。若重复安装前已经是中文，这一步仍会恢复为中文；更早状态可在相应时间戳备份的 `locale-backup.json` 找到。

开始菜单入口带有 `--lang=zh-CN` 参数。要完整回到官方安装，请按下一节操作，而不要把恢复单个字段当作完整卸载。

## 回到官方商店版

1. 完全退出 Claude，额外保存当前 `%LOCALAPPDATA%\Claude-3p` 等仍在使用的数据；不要用很久以前的备份覆盖它。
2. 打开开始菜单程序目录（Win+R 输入 `shell:programs`），删除本工具创建的 `Claude` 快捷方式。可在对应备份的 `shortcuts` 中查看原快捷方式；如果它指向旧的程序副本，不必恢复。
3. 确认 `%LOCALAPPDATA%\Programs\Claude` 是本工具安装目录后，可手动删除该程序目录。不要删除同级其他程序或用户数据目录。
4. 从 Microsoft Store 重新安装官方 Claude Desktop。此步骤需要联网，由商店安装对应服务和更新组件；本项目无法保证商店仍提供旧版本。
5. 启动官方版，检查账号、第三方网关配置和功能。必要时只恢复确实缺失的数据，不整体回滚新的配置。

本工具没有打包官方安装器或商店签名，因此无法提供离线恢复商店安装的“一键回滚”。原商店私有数据的备份是文件快照；只有确认官方版确实缺少这些数据时，才在应用退出后根据实际新目录人工恢复。

## 备份保存多久

每次安装保留独立时间戳备份，不会自动清理。确认配置、聊天和常用功能都正常后，可自行保留近期备份、删除不需要的旧备份。备份可能包含凭据，应放在自己的受保护账户目录中。
