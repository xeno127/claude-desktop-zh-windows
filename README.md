# Claude Desktop 简体中文补丁（Windows）

为 Windows 版 Claude Desktop 的本地界面添加简体中文选项，并保存为默认语言。安装后仍从原来的官方 Claude 入口打开。

## 支持范围

| 项目 | 当前范围 |
| --- | --- |
| 系统 | Windows x64；Python 3.10 或更新版本 |
| Claude | 精确匹配 3.1623.4.0，包族 Claude_pzs8sxrjxfjjc |
| 界面 | 第三方模式的本地界面、语言菜单及桌面菜单 |
| 官方账号 | 不在本补丁验证范围；优先使用官方页面自带语言设置 |
| Cowork | 本机安装中文后已实际确认可用；不保证所有硬件、账号和安装环境 |

安装器同时核对包注册、版本、EXE、ASAR及英文资源的 SHA256。其他版本或包族会停止，不能只修改版本号强装。目录拒绝写入时，即使管理员运行也可能无法安装；本工具会停止，不接管 WindowsApps 权限。

## 使用

1. 从 Releases 下载 v0.2.0 ZIP 并完整解压。
2. 从托盘完全退出 Claude。
3. 双击 **setup.cmd**，按 Windows UAC 提示授权，使用当前用户账户。
4. 安装结果窗口显示成功后关闭窗口，从原来的官方 Claude 入口打开。

需要 Python 3.10+，只使用标准库，无需 pip。找不到 Python 时，安装并加入 PATH，或设置环境变量 CLAUDE_ZH_PYTHON 指向自己的 python.exe。

管理员授权如果需要切换成另一位用户，安装器会拒绝，以免改错配置。安装器不会关闭正在执行的任务、自动启动 Claude或重启电脑。

在解压目录打开 PowerShell，可运行：

```powershell
.\setup.cmd check
.\setup.cmd verify
.\setup.cmd restore
```

- check：只读检查版本、资源、默认语言和 Cowork 服务状态。
- verify：只读验证中文资源及默认语言是否正确。
- restore：从本工具备份恢复补丁前的资源及语言字段，保留后来修改的其他配置。

详细参数见[安装与使用](docs/安装与使用.md)，异常和旧版迁移见[恢复与卸载](docs/恢复与卸载.md)。

## 改动与备份

只写入三个中文 JSON、一份 zh-Hans 桌面资源和前端语言菜单脚本；只将现有配置中的 locale 设置为 zh-CN。不会改动 EXE、ASAR、模型、密钥、网关地址、聊天记录、系统服务或官方启动入口。

安装前检测写权限，并备份将要改动的资源及当前配置。发生普通写入错误会尝试回滚；备份或资源发生冲突时停止。不会备份整套程序和全部聊天数据，也不负责离线恢复官方安装。

备份位置：%LOCALAPPDATA%\ClaudeZhPatch\backups。

官方更新可能覆盖中文资源或语言设置。更新后重新运行 check；只有版本与资源仍受支持时才能重新安装。保留官方更新能力不代表补丁能自动兼容以后版本。

## 翻译与验证

前端36,153条、桌面861条、动态文案49条，共37,063条。英文资源与当前受支持版本完全匹配；ICU语法及变量/标签结构验证报告位于 language-pack/validation.json。译文包含上游翻译、机器翻译和人工修订，尚未逐条人工审校所有页面。品牌、模型名、路径和在线页面可能保留原文。

本补丁仅处理界面语言，不提供模型服务、账号或API接入，不修改现有请求路由。服务端503、模型映射或账户权限问题需要在相应服务端处理。
