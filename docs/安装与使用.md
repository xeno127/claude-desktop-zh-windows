# 安装与使用

## 适用条件

当前语言包绑定 Claude Desktop **3.1623.1.0 x64**。请先安装官方程序并配置好第三方网关，确认原版能够打开，然后完全退出托盘中的 Claude。

默认安装面向 `Claude-3p` 配置。官方账号模式尚未验证，脚本默认拒绝将其他模式当作已支持环境。不提供绕过版本校验的开关。

需要 Python 3.10+。安装时检查系统盘空间是否足够容纳约 707 MB 程序及完整用户数据备份，不需要联网翻译或下载其他依赖。

## 双击安装

完整解压后双击 `setup.cmd`。检测到受支持商店版时，安装器会说明卸载、商店更新和 Cowork 服务变化，然后要求输入 `REPLACE`。输入其他文字或直接回车会取消，不改当前安装。

安装器先备份用户数据、校验备份，再复制并校验中文程序；准备完成后才卸载商店版。成功后仅更新当前用户开始菜单的 `Claude` 入口，日常直接点击即可。任务栏固定的旧商店图标和桌面旧快捷方式需要自己取消固定或删除，再固定新的 `Claude`。

安装器不自动操作界面、不杀进程、不发送模型请求。若 Claude 仍运行，会要求退出后重试。

## 命令行

在补丁目录打开 PowerShell：

```powershell
# 只检查，不更改系统。
.\setup.cmd check

# 安装或修复现有中文安装；有商店版时会再次要求确认。
.\setup.cmd

# 卸载已完成但后续配置失败时，继续迁移。
.\setup.cmd resume

# 恢复上次安装前的语言字段。
.\setup.cmd restore-language
```

需要自己指定 Python 或非标准配置路径时：

```powershell
python -X utf8 .\setup.py check
python -X utf8 .\setup.py install --app '原版的 app 目录' --config '现有配置目录\config.json'
```

`--app` 仍要求源文件版本及哈希完全匹配。`--config` 由用户明确指定已有配置；自定义配置在标准数据目录之外时，会备份其整个父目录，请不要把配置放在包含大量无关文件的位置。

环境变量 `CLAUDE_ZH_PYTHON` 可以指定解释器；`CLAUDE_ZH_NO_PAUSE=1` 仅关闭 CMD 结束时的“按任意键继续”，不跳过卸载确认，也不忽略错误。

## 为什么需要替换商店安装

原版第三方界面不含完整中文资源，语言目录也没有外部覆盖配置项，只改 `locale` 无法添加缺失语言。直接写 WindowsApps 在部分 MSIX 环境下会遭到拒绝，即使管理员也可能写不进去。

此工具在用户可写的标准程序目录保存中文版本，随后移除当前用户的商店注册，避免 Windows 搜索同时出现两个同名 Claude。它不会通过修改 ACL、注入进程或覆盖系统目录解决这个问题。

移除商店包后，该安装不再由商店自动更新，相关 Cowork 服务也会移除；不会自动安装替代服务。

## 常见问题

### 提示找不到 Python

从 Python 官方渠道安装 Python 3.10 或更新版本并加入 PATH，再重新运行。若已安装在自定义目录，可以直接用其解释器运行 `setup.py`。本项目不自动安装 Python。

### 安装目录已存在或文件校验失败

已经正确安装的同版本中文程序可复用，并重新备份、修复配置和快捷方式。若目录存在但文件哈希不同，脚本会停止，不会覆盖未知程序。先保存当前内容并查明版本，不要强制覆盖其他版本。

### 仍然英文

从托盘退出所有 Claude，再从开始菜单打开新 `Claude`。旧任务栏固定项可能还指向商店版；重新固定开始菜单项。运行 `setup.cmd check` 核对程序是否匹配。不要把其他版本的语言资源混进当前安装。

### Gateway 报错

汉化不创建模型通道，也不改网关、API 密钥或模型 ID。记录报错时间、请求 ID 和服务端返回内容，交由服务商检查；提交公开 issue 时先去掉密钥、账户等个人信息。

### 权限不足、备份失败或卸载失败

完整保留窗口输出，按[恢复与卸载](恢复与卸载.md)中的阶段处理。脚本不会自动提权、修改 WindowsApps 权限或反复卸载。备份失败时不会继续卸载。

### 应用更新后怎么办

当前工具严格锁定已验证版本。新版需要重新检查语言键、语言列表结构及源文件哈希，再更新补丁和验证记录。不要通过删除校验来“兼容”未知版本。
