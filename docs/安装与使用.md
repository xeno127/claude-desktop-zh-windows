# 安装与使用

## 准备

- Windows x64，Python 3.10+，当前用户可以通过UAC获得管理员权限。
- 官方 Claude 3.1623.4.0，包族 Claude_pzs8sxrjxfjjc，第三方模式已正常配置。
- 先确认原版的登录、聊天和需要的Cowork功能可用，再安装语言补丁。
- 从托盘完全退出Claude，完整解压补丁，保留文件相对位置。

## 安装

双击 setup.cmd；默认执行 install。当前账户的UAC授权窗口会出现，管理员结果窗口结束后可关闭。不要用另一位管理员账户的凭据替代当前用户。

```powershell
.\setup.cmd install
```

安装器先核对官方包、核心和资源哈希，确认应用已退出，检测目标文件和目录可写，备份原资源及配置。之后仅导入中文资源并设置locale，验证完成后记录恢复位置。应用仍从官方入口启动，无需CMD常驻。

不安装额外服务，不改变系统权限，不卸载或复制官方应用，不修改自动更新开关，不自动重启。Cowork可能由官方应用另行要求安装运行组件及重启，这不是语言补丁的安装步骤。

## 只读检查

```powershell
.\setup.cmd check
.\setup.cmd verify
```

这两项不申请管理员权限，不写探针、备份、配置或快捷方式，不关闭应用。check可用于安装前检查，也可检查现有补丁；verify要求中文资源全部正确且locale为zh-CN。只读检查通过不能证明目录可写，实际安装才进行写权限检测。

## 可选参数

```powershell
.\setup.cmd check --app '官方包的根目录或 app 目录'
.\setup.cmd install --config "$env:LOCALAPPDATA\Claude-3p\config.json"
```

--app必须对应受支持的已注册官方包，不能绕过包身份和版本检查。--config必须是当前Windows用户目录内已存在的JSON对象；默认使用 %LOCALAPPDATA%\Claude-3p\config.json。官方账号的在线界面优先使用官方语言设置，本补丁不注入在线网页。

Python未加入PATH时，可在PowerShell先指定解释器：

```powershell
$env:CLAUDE_ZH_PYTHON = '你的 python.exe 完整路径'
.\setup.cmd check
```

## 更新与重复运行

当前补丁及语言均正确时重复install不会覆盖原恢复点。如果是由其他工具或手工安装的中文，本工具可以检查验证，但没有原始备份时不能保证替它卸载；需要恢复时使用原工具的备份。

官方更新后先运行check。检测到新版本、不同包族或资源修改时停止，等待发布适配版本；不要降低版本检查或复制旧EXE。若安装后仍英文，先核对打开的是check显示的官方版本，而非旧副本或另一个并存安装。
