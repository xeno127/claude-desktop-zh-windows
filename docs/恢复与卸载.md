# 恢复与卸载

## 移除 v0.2.0 语言补丁

从托盘完全退出Claude，在本补丁目录执行：

```powershell
.\setup.cmd restore
```

这会恢复最近一次本工具安装前的语言资源；安装前不存在的新增中文文件会移除。配置仅恢复原locale字段；若原来无locale则移除该字段。后来修改的密钥、模型及其他设置保留。官方安装、Cowork服务和更新机制均保留。

恢复需要同一受支持官方版本和完好的资源备份。资源出现其他修改、官方核心更新或备份损坏时停止，避免用旧文件覆盖新版。此操作不是卸载Claude，不需要重新安装官方应用。

## 指定恢复点

备份位于 %LOCALAPPDATA%\ClaudeZhPatch\backups\时间戳。目录内的state.json记录原资源、补丁哈希、配置路径及事务阶段；config-before.json可能含凭据。不要修改这些记录或公开上传。

```powershell
.\setup.cmd restore --backup "$env:LOCALAPPDATA\ClaudeZhPatch\backups\你的备份目录"
```

只接受本工具backups目录下的直接子目录。没有本工具的恢复记录时，不会猜测或覆盖其他工具的备份。

## 安装失败或中断

- 版本、源文件或目录权限检查失败：尚未开始导入，不要卸载官方应用或修改WindowsApps权限。
- 写入阶段失败：安装器尝试恢复本次操作前的资源和配置。保留报错和备份。
- state.json为prepared：说明安装可能中断。退出Claude后运行restore；它校验官方核心和备份后，可恢复尚未完整写入的语言脚本。
- state.json为complete：安装完成；资源有其他工具修改时，恢复会报告冲突。
- state.json为restored：已恢复；原备份继续保留，不自动清理。

系统更新造成新旧官方包并存时，不要仅为了清理同名入口而卸载旧包。Cowork服务可能仍属于旧包；让官方更新器或系统安装流程处理。

## 使用过 v0.1 的用户

v0.1曾采用卸载商店包、运行中文副本的方案，会连带移除Cowork服务，现已废弃。请勿继续使用旧ZIP或resume命令。

先额外备份当前用户数据，通过官方来源重新安装Claude并确认Cowork恢复，再使用适配当前版本的资源补丁。旧版备份主要是文件快照，不能单靠覆盖文件恢复系统服务及包注册。

若旧普通快捷方式仍指向独立副本，可在Win+R输入shell:programs，核对该快捷方式目标后手动移除或更换为官方入口。不要删用户数据目录，不要卸载仍提供服务的官方包。v0.2.0不会擅自删除或修复旧快捷方式。

本工具没有官方安装器、账号数据或商店签名，不能提供官方应用的离线重新安装。确认一切正常后可自行清理不再需要的旧备份；含凭据的备份应保存在自己的账户内。
